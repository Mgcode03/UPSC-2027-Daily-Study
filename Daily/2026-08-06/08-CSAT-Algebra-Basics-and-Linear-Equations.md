# CSAT: Algebra Basics and Linear Equations

## Introduction to Algebra in CSAT

Algebra forms an important part of the Quantitative Aptitude section of the CSAT paper. Questions typically test the ability to translate word problems into equations, manipulate algebraic expressions, and solve linear equations in one or two variables. A clear understanding of basic concepts and regular practice with different types of problems are essential.

## Algebraic Expressions

An algebraic expression is a combination of constants, variables, and arithmetic operations. For example, 3x + 5, 2y – 7, and 4a + 3b – 2 are algebraic expressions.

- A constant is a symbol that has a fixed value (for example, 2, –5, 0, 3/4).
- A variable is a symbol that can take different values (commonly denoted by x, y, z, a, b, etc.).
- A term is a constant, a variable, or a product of constants and variables (for example, in 3x + 5, the terms are 3x and 5).
- Like terms have the same variables raised to the same powers (for example, 3x and 7x are like terms; 3x and 3y are unlike terms).
- The coefficient of a term is the numerical factor (in 5x, the coefficient of x is 5).

Expressions can be simplified by combining like terms. For example, 3x + 5x – 2x = 6x.

## Linear Equations in One Variable

A linear equation in one variable is an equation that can be written in the form ax + b = 0, where a and b are constants and a ≠ 0. The solution (or root) of the equation is the value of the variable that makes the equation true.

### Solving Linear Equations

The basic principle is that the same operation can be performed on both sides of the equation without changing the equality. The usual steps are:

1. Simplify both sides (expand brackets, combine like terms).
2. Move variable terms to one side and constant terms to the other side by adding or subtracting the same quantity on both sides.
3. Divide both sides by the coefficient of the variable to isolate the variable.

Example: Solve 3x – 7 = 2x + 5.

Subtract 2x from both sides: x – 7 = 5.
Add 7 to both sides: x = 12.

Verification: Left side = 3(12) – 7 = 36 – 7 = 29. Right side = 2(12) + 5 = 24 + 5 = 29. Both sides equal, so x = 12 is correct.

### Equations Involving Fractions

When an equation contains fractions, multiply both sides by the least common multiple (LCM) of the denominators to clear the fractions.

Example: Solve (x/2) + (x/3) = 10.

LCM of 2 and 3 is 6. Multiply both sides by 6: 3x + 2x = 60. 5x = 60. x = 12.

## Linear Equations in Two Variables

A linear equation in two variables is of the form ax + by + c = 0, where a, b, and c are constants and a and b are not both zero. Such an equation has infinitely many solutions. To find a unique solution, a pair of independent linear equations in the same two variables is needed. This is called a system of simultaneous linear equations.

### Methods of Solution

#### Substitution Method
Solve one equation for one variable in terms of the other, and substitute the expression into the second equation.

Example: Solve
x + y = 5
2x – y = 4

From the first equation, y = 5 – x. Substitute into the second: 2x – (5 – x) = 4. 2x – 5 + x = 4. 3x = 9. x = 3. Then y = 5 – 3 = 2.

#### Elimination Method
Multiply one or both equations by suitable numbers so that the coefficients of one variable become equal (or equal in magnitude but opposite in sign). Add or subtract the equations to eliminate that variable.

Example: Solve
2x + 3y = 8
3x + 2y = 7

Multiply the first equation by 2 and the second by 3: 4x + 6y = 16 and 9x + 6y = 21. Subtract the first from the second: 5x = 5. x = 1. Substitute into 2(1) + 3y = 8: 2 + 3y = 8. 3y = 6. y = 2.

#### Cross-Multiplication Method (for two equations)
For the system
a1x + b1y + c1 = 0
a2x + b2y + c2 = 0

the solution is given by
x / (b1c2 – b2c1) = y / (c1a2 – c2a1) = 1 / (a1b2 – a2b1)

provided the denominator is not zero.

## Word Problems

Many CSAT questions present situations in words that must be translated into equations.

### Steps for Solving Word Problems
1. Read the problem carefully and identify what is asked.
2. Assign variables to the unknown quantities.
3. Translate the given information into equations using the relationships stated in the problem.
4. Solve the equations.
5. Check that the solution makes sense in the context of the problem (for example, quantities cannot be negative if the context does not allow it).

### Common Types
- Age problems: Relations between present and future or past ages.
- Number problems: Sum, difference, product, or digit relationships.
- Mixture and alligation type problems that can be set up as linear equations.
- Work and rate problems that reduce to linear relations.
- Distance, speed, and time problems that can be expressed algebraically.

Example: The sum of two numbers is 45 and their difference is 9. Find the numbers.

Let the numbers be x and y. Then x + y = 45 and x – y = 9. Adding: 2x = 54, x = 27. Then y = 18.

## Special Products and Identities (Useful for Simplification)

- (a + b)² = a² + 2ab + b²
- (a – b)² = a² – 2ab + b²
- (a + b)(a – b) = a² – b²
- (a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca

These identities help in expanding and factorising expressions quickly.

## Practice Orientation

In the examination, speed and accuracy are both important. Practice solving equations and word problems under timed conditions. Always verify the solution by substitution when time permits. For data sufficiency questions involving equations, determine whether the given statements are sufficient to find a unique value of the unknown, without necessarily solving completely if sufficiency can be judged earlier.

A solid command of linear equations and the ability to translate verbal information into algebraic form form the foundation for many quantitative problems in the CSAT paper.
